  # Дипломный проект по курсу «Python-разработчик с нуля»

## VKinder

### Цель проекта

Цель проекта — разработать программу-бота для взаимодействия с API социальной сети ВКонтакте. Бот будет предлагать различные варианты людей для знакомств в социальной сети ВКонтакте в виде диалога с пользователем, сохраняя данные об избранных пользователях в файлах на диске.

Вам предстоит:
- разработать программу-бота на Python,
- спроектировать и реализовать систему хранения данных с использованием файлов (в формате JSON),
- настроить взаимодействие бота с ВКонтакте,
- написать документацию по использованию программы.

В результате выполнения этого задания вы:
- получите практический опыт создания чат-бота,
- закрепите навыки работы с GitHub и программирования на языке Python,
- разработаете с нуля полноценный программный продукт, который можно будет добавить в портфолио Python-разработчика.

### Инструкция для работы над проектом

Нужно разработать программу-бота, который выполняет действия:

1. Используя информацию (возраст, пол, город) о пользователе, который общается с ботом в ВКонтакте, сделать поиск других пользователей ВКонтакте для знакомств.
2. У тех людей, которые подошли под критерии поиска, получить три самые популярные фотографии в профиле. Популярность определяется по количеству лайков.
3. Выводить в чат с ботом информацию о пользователе в формате:
```
- имя и фамилия,
- ссылка на профиль,
- три фотографии в виде attachment.
```
[Документация](https://dev.vk.com/method/messages.send)

4. Должна быть возможность перейти к следующему человеку с помощью команды или кнопки.
5. Сохранить пользователя в список избранных — данные должны записываться в файл favorites.json в корне проекта.
6. Вывести список избранных людей — данные должны читаться из файла favorites.json.

[Пример структуры файла favorites.json](https://github.com/netology-code/spd-diplom/blob/SPD-diplom-132/example_favorite.json)

Используйте модуль datetime для записи времени добавления. Используйте json.dump() и json.load() для записи и чтения. 

*Обратите внимание: инструкция для получения токена для ВК находится в вашем личном кабинете в итоговом блоке по модулю.*

### План работы
  
### 1 этап:
1. Создайте общий репозиторий на GitHub.
2. Спроектируйте структуру данных, которые будут храниться в файле favorites.json. Опишите в README.md или отдельном файле DATA_SCHEMA.md, какие поля вы сохраняете и зачем.
### 2 этап:
1. Разработайте взаимодействие с ВКонтакте для получения информации о пользователях и их фотографий. Можно использовать готовые библиотеки (например, vk_api).
2. Реализуйте модуль для работы с файлом favorites.json:
    - функция add_to_favorites(user_data) — добавляет пользователя в список,
    - функция get_favorites() — возвращает список избранных,
    - функция load_favorites() — читает данные из файла,
    - функция save_favorites(data) — записывает данные в файл,
    - обработайте случай, когда файл отсутствует — создайте его с пустым списком [].
### 3 этап:	
1. Разработайте взаимодействие с ботом. Можно воспользоваться этим [шаблоном](basic_code.py). Будет плюсом, если вы добавите кнопки для более удобного взаимодействия с пользователем. 
2. Подготовьте проект к сдаче работы. Исправьте ошибки.
3. Реализуйте интеграцию бота с файловой системой (чтение/запись избранного).
4. Напишите документацию (README.md) с инструкцией по запуску и описанием структуры файла favorites.json.
5. Подготовьте проект к сдаче курсовой работы. Исправьте ошибки.

### Дополнительные требования к проекту (не обязательны для получения зачёта)

1. Получать токен от пользователя с нужными правами.
2. Добавлять человека в чёрный список, чтобы он больше не попадался при поиске — реализуйте через файл blacklist.json по аналогии с favorites.json.
3. Создать кнопки в чате для взаимодействия с ботом.
4. Добавить возможность ставить/убирать лайк выбранной фотографии.
5. К списку фотографий из аватарок добавлять список фотографий, где отмечен пользователь.
6. В ВКонтакте максимальная выдача при поиске — 1 000 человек. Подумайте, как это ограничение можно обойти.
7. Можно усложнить поиск, добавив поиск по интересам. Разбор похожих интересов — группы, книги, музыка — нужно будет провести с помощью анализа текста.
8. У каждого критерия поиска должны быть свои веса, то есть совпадение по возрасту должно быть важнее общих групп, интересы по музыке — важнее книг, наличие общих друзей — важнее возраста и т. д.

### Критерии оценки

Зачёт по разработанному проекту ставится, если созданный программный продукт соответствует критериям:
- Отсутствуют ошибки (traceback) во время выполнения программы.
- Результат программы (данные об избранных пользователях) записывается в файл favorites.json. Приложено описание структуры данных (схема файла).
- Программа добавляет человека в избранный список, используя файловую систему (JSON-файл).
- Программа декомпозирована на функции/классы/модули/пакеты.
- Написана документация по использованию программы (в README.md).
- Код программы удовлетворяет PEP8. Перед отправкой решения на проверку проверьте код с помощью линтеров (например, flake8, pylint или встроенных средств IDE).
